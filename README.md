# 會員照片快速修圖工具 V12.7（GitHub Pages / MediaPipe）

## 部署方式

1. 將此資料夾內的所有檔案放到 GitHub repository 根目錄：
   - `index.html`
   - `style.css`
   - `app.js`
   - `.nojekyll`
2. GitHub repository → **Settings → Pages**
3. Build and deployment 選 **Deploy from a branch**
4. Branch 選 `main`、Folder 選 `/ (root)`
5. 儲存後等待 GitHub Pages 發布。

如果 repository 名稱是 `member-photo-editor`，網址通常會是：

`https://你的帳號.github.io/member-photo-editor/`

## V12 的人臉處理

V12 使用 MediaPipe Face Landmarker：

- JavaScript / WASM：從 jsDelivr CDN 載入
- Face Landmarker 模型：從 Google MediaPipe 模型儲存空間載入
- 所有會員照片仍在使用者瀏覽器內處理，程式沒有照片上傳 API

MediaPipe 用於：
- 2 吋大頭照自動裁切
- 批次自動裁切
- 臉部輪廓 / 五官定位
- 智慧臉部去污的安全皮膚遮罩

如果 MediaPipe 因網路或 CDN 無法載入：
- 自動找臉 / 自動 2 吋裁切 / 臉部智慧去污會無法使用
- 旋轉、手動裁切、亮度、對比、飽和度、銳化、去污筆、下載等功能仍可正常使用

## 2 吋裁切方向

- 比例：3.5 × 4.5 公分
- 頭頂至下顎：目標約佔照片高度 75%
- 合理方向：70%～80%
- 自動裁切只產生建議框；單張模式仍可微調後再套用
- 批次模式會直接套用，未辨識到可靠臉部的照片會跳過

## 注意

`file://` 直接雙擊開啟時，瀏覽器對 ES Module / CDN 的安全限制可能不同。
正式使用建議放在 GitHub Pages、localhost 或其他 HTTPS 靜態網站環境。


## V12.1 修正

V12 原版使用靜態 default import 載入 MediaPipe CDN。在某些瀏覽器 / jsDelivr
套件入口組合下，JavaScript 可能在 app.js 模組解析階段直接中止，畫面因此永久顯示
「MediaPipe 載入中…」。

V12.1 改為：
- dynamic import
- 固定 `@mediapipe/tasks-vision@1.0.1`
- WASM 與 JS 使用相同版本
- JavaScript / WASM / 模型都有載入逾時處理
- 失敗時右上角會顯示實際錯誤，而不是無限「載入中」
- 載入失敗時可直接點右上角狀態重新嘗試

部署 GitHub Pages 後，建議按 Ctrl+F5 強制重新整理，避免瀏覽器沿用舊的 app.js 快取。


## V12.2 版面改版

V12.2 將操作介面改為桌面修圖軟體式固定工作區：

- 整個桌面版頁面不再上下捲動
- 上方固定 Ribbon：上傳、旋轉、自動 2 吋、裁切、修改前對比、復原、縮放、批次操作
- 左側照片欄：批次縮圖清單獨立捲動
- 中央照片工作區：永遠固定在可視範圍，放大後只有中央區自己捲動
- 右側工具欄：影像 / 去污 / 裁切 / 匯出四個 Tab，工具欄自己捲動
- 左右側欄都可以收合，方便 200%～400% 細修
- 下方固定狀態列

桌面版建議使用 1280px 以上寬度。窄螢幕會自動改為一般垂直版面。


## V12.3：100% 瀏覽器比例 / Office Ribbon

V12.3 將 V12.2 一次攤開全部按鈕的 Ribbon 改為真正的分頁式 Ribbon：

- 常用：上傳、旋轉、自動 2 吋、裁切、修改前比較、復原
- 批次：加入多張、上一張/下一張、全批 2 吋、提亮、去污、ZIP
- 檢視：照片縮放、適合視窗、收合左右欄
- 「照片」「檢視」等文字全部改為正常橫排，不再使用顛倒的直排文字
- 1366 / 1440 / 1600px 桌面寬度維持正常字級，不需要把瀏覽器縮到 60%
- 左欄與右欄稍微縮窄，把更多空間留給中央照片工作區


## V12.4 功能調整

- 照片縮放控制移到中央照片上方，永遠可見。
- 裁切進入後，中央照片區直接顯示「確認並完成裁切 / 取消」。
- 「照片灰塵 / 小型損傷」改為孤立污點 + 邊緣保護演算法。
- 新增 MediaPipe Image Segmenter 去背：
  - 白色背景
  - 透明背景
  - 邊緣柔化
  - 透明背景建議 PNG；JPG 自動填白


## V12.5 修正

- 修正啟動「2 吋裁切建議 / 手動裁切」時照片被往右推的問題。
  原因不是 4K 螢幕，而是 V12.4 的裁切確認列仍是 Stage Flex 容器中的排版元素。
  V12.5 改為絕對定位浮動工具列，不再佔用照片工作區的排版寬度。
- 裁切比例新增 `9 : 16 直式`。


## V12.6 批次功能

- 批次 Ribbon 內所有「全批」文字統一改為「批次」：
  - 批次自動 2 吋
  - 批次智慧提亮
  - 批次臉部去污
- 新增：
  - 批次去背（白色）
  - 批次去背（透明）
- 批次去背逐張使用 MediaPipe Image Segmenter。
- 單張去背失敗時只跳過該張，不會中止整批。
- 批次去背（透明）會將該張照片標記為透明影像：
  - 切換照片時以 PNG 保存透明度
  - 下載批次 ZIP 時透明照片輸出 PNG
  - 其他非透明照片仍輸出 JPG


## V12.7 批次 Ribbon 版面調整

批次功能增加後，V12.6 的批次 Ribbon 在桌面寬度下仍顯得擁擠。
V12.7 改為批次分頁專用的兩列式 Ribbon：

- 照片清單：加入多張、上一張、下一張
- 批次處理：
  - 第一列：批次自動 2 吋、批次智慧提亮、批次臉部去污
  - 第二列：批次去背（白色）、批次去背（透明）
- 完成 / 匯出：標記完成、下載全部 ZIP、清空批次

只有切到「批次」分頁時 Ribbon 才會增加高度；切回「常用 / 檢視」會恢復原本高度。
若瀏覽器寬度不足，批次 Ribbon 會自行橫向捲動，不縮小字體。
