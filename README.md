# 會員照片標準化工作站 V13.5（GitHub Pages / MediaPipe）

## 部署方式

1. 將此資料夾內的所有檔案放到 GitHub repository 根目錄：
   - `index.html`
   - `style.css`
   - `app.js`
   - `.nojekyll`
2. GitHub repository → **Settings → Pages**
3. Build and deployment 選 **Deploy from a branch**
4. Branch 選 `main`、Folder 選 `/ (root)`
5. 儲存後等待 GitHub Pages 發布。

如果 repository 名稱是 `member-photo-editor`，網址通常會是：

`https://你的帳號.github.io/member-photo-editor/`

## V12 的人臉處理

V12 使用 MediaPipe Face Landmarker：

- JavaScript / WASM：從 jsDelivr CDN 載入
- Face Landmarker 模型：從 Google MediaPipe 模型儲存空間載入
- 所有會員照片仍在使用者瀏覽器內處理，程式沒有照片上傳 API

MediaPipe 用於：
- 2 吋大頭照自動裁切
- 批次自動裁切
- 臉部輪廓 / 五官定位
- 智慧臉部去污的安全皮膚遮罩

如果 MediaPipe 因網路或 CDN 無法載入：
- 自動找臉 / 自動 2 吋裁切 / 臉部智慧去污會無法使用
- 旋轉、手動裁切、亮度、對比、飽和度、銳化、去污筆、下載等功能仍可正常使用

## 2 吋裁切方向

- 比例：3.5 × 4.5 公分
- 頭頂至下顎：目標約佔照片高度 75%
- 合理方向：70%～80%
- 自動裁切只產生建議框；單張模式仍可微調後再套用
- 批次模式會直接套用，未辨識到可靠臉部的照片會跳過

## 注意

`file://` 直接雙擊開啟時，瀏覽器對 ES Module / CDN 的安全限制可能不同。
正式使用建議放在 GitHub Pages、localhost 或其他 HTTPS 靜態網站環境。


## V12.1 修正

V12 原版使用靜態 default import 載入 MediaPipe CDN。在某些瀏覽器 / jsDelivr
套件入口組合下，JavaScript 可能在 app.js 模組解析階段直接中止，畫面因此永久顯示
「MediaPipe 載入中…」。

V12.1 改為：
- dynamic import
- 固定 `@mediapipe/tasks-vision@1.0.1`
- WASM 與 JS 使用相同版本
- JavaScript / WASM / 模型都有載入逾時處理
- 失敗時右上角會顯示實際錯誤，而不是無限「載入中」
- 載入失敗時可直接點右上角狀態重新嘗試

部署 GitHub Pages 後，建議按 Ctrl+F5 強制重新整理，避免瀏覽器沿用舊的 app.js 快取。


## V12.2 版面改版

V12.2 將操作介面改為桌面修圖軟體式固定工作區：

- 整個桌面版頁面不再上下捲動
- 上方固定 Ribbon：上傳、旋轉、自動 2 吋、裁切、修改前對比、復原、縮放、批次操作
- 左側照片欄：批次縮圖清單獨立捲動
- 中央照片工作區：永遠固定在可視範圍，放大後只有中央區自己捲動
- 右側工具欄：影像 / 去污 / 裁切 / 匯出四個 Tab，工具欄自己捲動
- 左右側欄都可以收合，方便 200%～400% 細修
- 下方固定狀態列

桌面版建議使用 1280px 以上寬度。窄螢幕會自動改為一般垂直版面。


## V12.3：100% 瀏覽器比例 / Office Ribbon

## V12.6 批次功能

- 批次 Ribbon 內所有「全批」文字統一改為「批次」：
  - 批次自動 2 吋
  - 批次智慧提亮
  - 批次臉部去污
- 新增：
  - 批次去背（白色）
  - 批次去背（透明）
- 批次去背逐張使用 MediaPipe Image Segmenter。

  - 其他非透明照片仍輸出 JPG


## V12.7 批次 Ribbon 版面調整

批次功能增加後，V12.6 的批次 Ribbon 在桌面寬度下仍顯得擁擠。
V12.7 改為批次分頁專用的兩列式 Ribbon：

- 照片清單：加入多張、上一張、下一張
- 批次處理：
  - 第一列：批次自動 2 吋、批次智慧提亮、批次臉部去污
  - 第二列：批次去背（白色）、批次去背（透明）
- 完成 / 匯出：標記完成、下載全部 ZIP、清空批次

只有切到「批次」分頁時 Ribbon 才會增加高度；切回「常用 / 檢視」會恢復原本高度。
若瀏覽器寬度不足，批次 Ribbon 會自行橫向捲動，不縮小字體。


## V12.8 批次 Ribbon 顯示修正

V12.7 的三組按鈕都存在，但 `width:max-content` + Flex + 固定高度的組合，
在部分瀏覽器下會讓「批次處理」「完成 / 匯出」落到異常的可視位置。

V12.8 改成直接三欄 CSS Grid：

1. 照片清單
2. 批次處理
3. 完成 / 匯出

中間「批次處理」固定使用 3 + 2 兩列排列。
1366 / 1440 / 4K 桌面畫面都會優先讓三個群組同時顯示；
只有真正低於可容納寬度時，Ribbon 本身才會橫向捲動。

## V12.12 操作教學按鈕修正

V12.11 的教學內容本來就內建在 `index.html`，不需要額外建立教學網頁。

若 GitHub Pages 更新時只刷新了 `index.html`，但瀏覽器仍沿用舊版 `app.js`，
可能出現「看得到 ❓ 操作教學按鈕，但點擊沒有反應」。

V12.12 調整：
- 教學視窗的開啟 / 關閉事件直接由 `index.html` 內的小型獨立程式控制
- 不再依賴 MediaPipe 或主 `app.js` 是否成功載入
- `style.css` 改為 `style.css?v=12.12`
- `app.js` 改為 `app.js?v=12.12`
- 透過版本參數降低 GitHub Pages / 瀏覽器沿用舊快取的機率

因此只要 V12.12 的 `index.html` 與 `style.css` 有更新，操作教學即可正常開啟。


## V13 大版本：會員照片標準化工作站

V13 將工具由「單純修圖」升級成會員照片的標準化工作流程，包含：
1. 一鍵會員照標準化
2. 照片品質檢查與合格 / 待確認 / 需人工分類
3. 依雙眼 Landmark 自動轉正
4. 去背遮罩「保留人物 / 移除背景」細修
5. 批次工作佇列與狀態篩選
6. 批次處理 Preset
7. 批次檔名規則與 TXT / CSV 名稱清單
8. IndexedDB 自動儲存 / 恢復工作階段
9. Before / After 滑動比較
10. AI 引擎狀態、按需載入與記憶體釋放

## V13.2 手動轉正

右側「影像」→「影像調整」新增手動轉正：

- 範圍：`-15° ~ +15°`
- 精度：`0.1°`
- 快速微調：`-0.5° / 歸零 / +0.5°`
- 拖曳角度時只使用 CSS 做中央照片即時預覽
- 按「套用手動轉正」後才從目前來源照片重新取樣一次，避免拖曳過程反覆旋轉造成畫質劣化

- 套用後會進入復原 / 重做歷史紀錄
- 批次模式中單張微調後也會保存到目前照片
- `help.html` 已同步新增手動轉正說明


## V13.3 新增會員照 2.1 × 2.3 公分裁切

右側「裁切」→「裁切比例」新增：

- `會員照 2.1 × 2.3 公分`
- 寬：`2.1 cm`
- 高：`2.3 cm`
- 固定比例：`21 : 23`

## V13.4 一鍵標準化改用會員照 2.1 × 2.3 公分

V13.3 的「✨ 一鍵標準化」原本仍沿用 2 吋大頭照 3.5 × 4.5 cm。
V13.4 已改為：

- 一鍵標準化裁切：`會員照 2.1 × 2.3 cm`
- 固定比例：`21 : 23`
- 頭頂至下顎建議比例：維持約 `75%`，品質檢查允許範圍仍以 70%～80% 為主要合格區間
- 批次 `會員卡標準｜白底`
- 批次 `會員卡標準｜保留背景`
- 批次 `會員卡標準｜透明背景`
- `只做會員照裁切`

品質檢查也同步改為會員照標準：

- 比例目標：`2.1 : 2.3`
- 300dpi 最低參考：約 `248 × 272 px`

原本獨立的：
- `🎯 2 吋裁切建議`
- `🎯 自動 2 吋`
- 裁切比例 `2 吋大頭照 3.5 × 4.5 公分`

全部保留，不受一鍵標準化變更影響。

下列兩個原本仍使用 2 吋 3.5 × 4.5 cm 的功能已改成會員照：

- `🎯 2 吋裁切建議` → `🎯 會員照裁切建議`
- `🎯 自動 2 吋` → `🎯 自動會員照`

兩個功能的實際裁切邏輯同步改為：

- 寬：`2.1 cm`

- 一鍵標準化
- 會員照裁切建議
- 批次自動會員照
